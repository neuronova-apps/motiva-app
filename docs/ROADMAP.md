# Hoja de ruta de Motiva

## Etapa 1 — Experiencia web

- identidad visual clara;
- frase del día;
- categorías;
- exploración por necesidad;
- generador de frases de exhibición;
- atribución de autor y fuente;
- accesibilidad compartida.

## Etapa 2 — Flujo editorial

- definir estados publicables;
- automatizar exportación de frases aprobadas;
- validar derechos y fuentes antes de publicación;
- controlar duplicados;
- mantener tratamiento especial para contenido sensible.

## Etapa 3 — Aplicación móvil

- biblioteca ampliada;
- favoritos;
- historial;
- notificaciones de frase diaria;
- colecciones;
- filtros por categoría, necesidad y tono.

## Etapa 4 — Personalización

- preferencias de contenido;
- perfiles de espiritualidad cuando corresponda;
- frecuencia de notificaciones;
- opciones para compartir;
- colecciones personales.

## Etapa 5 — Evolución

- sincronización de preferencias;
- mejoras de accesibilidad;
- nuevas colecciones;
- análisis de uso sin comprometer privacidad;
- ampliación del banco maestro con criterios editoriales consistentes.

## Prioridad

La calidad y seguridad editorial de las frases tienen prioridad sobre aumentar rápidamente la cantidad de contenido visible.
