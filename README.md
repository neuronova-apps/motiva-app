# Motiva

Motiva es una iniciativa personal orientada a ofrecer frases breves de reflexión, motivación, inspiración y acompañamiento cotidiano mediante una experiencia digital clara, serena y accesible.

Forma parte del ecosistema [Neuronova Apps](https://neuronova-apps.github.io/) y se desarrolla como un proyecto personal e independiente de Gabriel Berrospi.

## Propósito

Motiva busca transformar un banco maestro de frases cuidadosamente organizado en una experiencia sencilla para el usuario.

La aplicación permite acercarse al contenido desde distintas rutas:

- una frase principal para cada día;
- categorías temáticas;
- necesidades asociadas al momento del usuario;
- exploración de frases;
- futuras colecciones, favoritos e historial en la aplicación completa.

Motiva no constituye un servicio psicológico, terapéutico ni de atención en salud mental. Sus contenidos tienen un propósito general de reflexión, inspiración y entretenimiento.

## Banco maestro de frases

La estructura editorial de Motiva se apoya en un banco maestro que organiza cada entrada mediante campos como:

- ID;
- frase;
- autor;
- obra o fuente;
- referencia o enlace;
- categoría principal;
- categorías secundarias;
- necesidad asociada;
- tono;
- espiritualidad;
- religión;
- astrología y signo cuando corresponda;
- longitud;
- estado de derechos;
- nivel de verificación;
- calidad editorial;
- estado editorial;
- control de duplicados;
- sensibilidad;
- observaciones;
- país u origen;
- etapa o colección.

Esta estructura permite separar la experiencia pública del trabajo editorial interno. El usuario ve una interfaz sencilla, mientras el banco conserva información necesaria para revisar calidad, derechos, fuentes y sensibilidad antes de publicar una frase.

- calma;

- seguir adelante;
- reflexionar;

- comprenderse;

Esta dimensión permite que Motiva no se limite a mostrar frases al azar, sino que pueda relacionar el contenido con una intención concreta de consulta.

## Frase del día

La web incorpora una frase principal diaria.

La selección se mantiene estable durante toda la fecha local del usuario y cambia automáticamente al iniciar un nuevo día. Esto evita que la frase principal cambie cada vez que se actualiza la página.

La primera versión utiliza una selección curada de frases aptas del banco maestro. La integración futura podrá ampliar la colección manteniendo los criterios de estado editorial, verificación, derechos y sensibilidad.

## Experiencia web

La web inicial de Motiva incorpora:

- portada clara y serena, diferenciada visualmente de las otras aplicaciones del ecosistema;
- frase del día;
- pausa reflexiva breve de 20 segundos;
- exploración por necesidad;
- mapa de categorías;
- selector de categorías;
- generación de frases de exhibición;
- atribución visible cuando existe autor o fuente;
- diseño responsive;
- integración con la accesibilidad central de Neuronova Apps.

## Identidad visual

Motiva utiliza una interfaz de fondo claro con tonos marfil, salvia, azul grisáceo y lavanda suave.

La intención es transmitir calma, reflexión y cercanía sin abandonar la identidad tecnológica de Neuronova Apps. Por ello se mantienen recursos como:

- cuadrícula ambiental sutil;
- transparencias;
- microanimaciones;
- elementos orbitales;
- controles interactivos;
- navegación clara;
- componentes visuales consistentes.

## Accesibilidad

Motiva consume el módulo central de accesibilidad alojado en el repositorio raíz de Neuronova Apps.

Entre sus funciones se encuentran:

- tamaño de texto en tres niveles;
- alto contraste;
- espaciado de letras y palabras;
- interlineado amplio;
- modo de lectura amigable para dislexia;
- guía de lectura;
- resaltado de enlaces;
- reducción de movimiento;
- foco de teclado reforzado;
- persistencia de preferencias entre aplicaciones del mismo ecosistema.

## Alcance de la aplicación completa

La web funciona como puerta de entrada y espacio de descubrimiento.

La aplicación podrá concentrar progresivamente funciones más amplias como:

- biblioteca completa de frases;
- favoritos;
- historial;
- colecciones personalizadas;
- notificaciones de frase diaria;
- filtros por categoría, tono o necesidad;
- preferencias de espiritualidad;
- perfiles de contenido;
- opciones para compartir;
- experiencias adicionales de lectura y reflexión.

## Criterio editorial

La publicación de una frase no depende únicamente de que exista en el banco maestro. También debe considerarse su estado editorial, verificación, situación de derechos, duplicidad y sensibilidad.

Las entradas sensibles o en revisión no deben utilizarse automáticamente como frase del día ni mostrarse como contenido público hasta completar la revisión correspondiente.

## Desarrollo

Motiva se encuentra en desarrollo activo. La interfaz, colección pública y funciones pueden modificarse conforme avancen las pruebas de contenido, accesibilidad y experiencia de usuario.
